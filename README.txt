MODERN STUDENT PORTFOLIO TEMPLATE
Built with React + Vite + Tailwind CSS

-------------------------------------
INSTALLATION GUIDE
-------------------------------------

1. Install Node.js (https://nodejs.org)
2. Open the project folder in terminal
3. Run: npm install
4. Run: npm run dev
5. Open the local link shown in terminal

-------------------------------------
HOW TO CUSTOMIZE
-------------------------------------

- Change name and hero content:
  src/sections/Hero.tsx

- Edit About section:
  src/sections/About.tsx

- Update Skills:
  src/sections/Skills.tsx

- Replace profile image:
  public/

-------------------------------------
BUILD FOR PRODUCTION
-------------------------------------

Run:
npm run build

The production files will be inside:
dist/

-------------------------------------
DEPLOY OPTIONS
-------------------------------------

Recommended:
- Vercel
- Netlify

-------------------------------------
SUPPORT
-------------------------------------

This template is beginner-friendly and fully customizable.
